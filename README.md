# TCP Chat

Небольшой консольный чат на **Rust**, который использует TCP-соединение для обмена текстовыми сообщениями и передачи файлов между двумя компьютерами.

Проект демонстрирует работу с TCP-сокетами, двоичным форматом пакетов, потоками, файловой системой и обработкой ошибок.

## Возможности

- **Обмен текстовыми сообщениями** в обе стороны.
- **Передача файлов** между клиентом и сервером.
- **Ограничение размеров данных:** программа проверяет размер сообщений, файлов и имён файлов.
- **Проверка имён входящих файлов:** запрещённые символы и попытки указать путь к другой директории отклоняются.
- **Защита от перезаписи:** существующие файлы не заменяются.
- **Автоматическая нумерация файлов:** если файл с таким именем уже есть, новый сохраняется с суффиксом, например `photo (1).png`.
- **Завершение соединения командой `/quit`.**
- **Общий сетевой протокол:** логика формирования и чтения пакетов вынесена в отдельный модуль и не дублируется в клиенте и сервере.

## Требования

- Установленный [Rust](https://www.rust-lang.org/tools/install) вместе с Cargo.
- Терминал для запуска сервера и клиента.

В проекте не используются сторонние Rust-зависимости.

## Структура проекта

```text
src/
├── main.rs         # Точка входа и выбор режима запуска
├── server.rs       # Запуск TCP-сервера и ожидание клиента
├── client.rs       # Подключение к серверу
├── connection.rs   # Обмен данными и обработка команд чата
└── protocol.rs     # Формат пакетов, отправка и получение данных

Cargo.toml          # Метаданные и настройки Rust-проекта
```

## Запуск

Открой терминал в корневой папке проекта.

### 1. Запустить сервер

В первом терминале выполни:

```bash
cargo run -- server
```

Сервер начнёт ожидать подключение на порту `8080`.

### 2. Подключить клиента

Во втором терминале выполни:

```bash
cargo run -- client 127.0.0.1:8080
```

`127.0.0.1` — адрес localhost. Он подходит, когда клиент и сервер запущены на одном компьютере.

### Подключение с другого компьютера в локальной сети

1. Запусти сервер на компьютере, который будет принимать подключение.
2. Узнай его локальный IP-адрес, например `192.168.1.100`.
3. На другом компьютере запусти клиент, указав IP-адрес сервера:

```bash
cargo run -- client 192.168.1.100:8080
```

Убедись, что устройства находятся в одной сети и брандмауэр разрешает входящие TCP-подключения на порт `8080`.

> Сервер слушает `0.0.0.0:8080`, то есть принимает подключения через доступные сетевые интерфейсы. Текущая версия сервера обслуживает **одного клиента за запуск**. Чтобы принять следующего клиента, перезапусти сервер.

## Команды чата

| Команда              | Действие                             |
| -------------------- | ------------------------------------ |
| `/file путь_к_файлу` | Отправить файл собеседнику           |
| `/quit`              | Завершить соединение и выйти из чата |

Пример отправки файла:

```text
/file ./documents/report.pdf
```

Обычный текст, не начинающийся с `/file ` и не равный `/quit`, отправляется собеседнику как сообщение.

## Получение файлов

Принятые файлы сохраняются в папку `downloads` относительно текущей рабочей директории — обычно это корневая папка проекта, из которой запущена команда `cargo run`.

Если файл с таким именем уже существует, программа не перезаписывает его, а подбирает свободное имя:

```text
downloads/
├── photo.png
├── photo (1).png
└── photo (2).png
```

## Ограничения

| Параметр                      |        Ограничение |
| ----------------------------- | -----------------: |
| Размер текстового сообщения   |              1 MiB |
| Размер передаваемого файла    |            100 MiB |
| Длина имени файла             |   255 байт в UTF-8 |
| Количество клиентов на сервер | 1 клиент за запуск |

Размеры проверяются и при отправке, и при получении данных.

## Как устроен протокол

Каждый пакет начинается с однобайтового типа. Многобайтовые числовые поля передаются в сетевом порядке байтов (**Big-endian**).

### Текстовое сообщение — тип `0`

```text
[тип: 1 байт]
[длина сообщения: 4 байта]
[текст в UTF-8: указанное количество байтов]
```

### Файл — тип `1`

```text
[тип: 1 байт]
[длина имени: 2 байта]
[имя файла в UTF-8: указанное количество байтов]
[размер файла: 8 байт]
[содержимое файла: указанное количество байтов]
```

### Завершение соединения — тип `2`

```text
[тип: 1 байт]
```

Получатель читает из TCP-потока ровно столько байтов, сколько указано в заголовке пакета. Благодаря этому следующий пакет начинается с правильной границы.

## Сборка

Проверить проект:

```bash
cargo check
```

```bash
cargo build --release
```

После сборки бинарный файл будет находиться в `target/release/`.

## Безопасность

Эта программа предназначена для обучения и использования в доверенной локальной сети. В текущей версии **нет шифрования TLS и аутентификации пользователей**. Передаваемые сообщения и файлы не защищены от просмотра или подмены участниками, способными перехватывать трафик.

Не выставляй сервер напрямую в публичный интернет. Для такого сценария необходимо добавить как минимум аутентификацию, защищённое соединение (например, TLS) и дополнительные меры защиты.
